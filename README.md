# 🍔 Ponto do Lanche

A responsive digital menu application developed for **Ponto do Lanche**, designed to provide customers with a simple and intuitive way to browse products, manage their shopping cart, and place orders through WhatsApp.

## 🚀 Live Demo

**[Access the application](https://ponto-do-lanche-rho.vercel.app/)**

## 📋 About the Project

Ponto do Lanche is a digital menu application focused on usability, responsiveness, and a smooth ordering experience.

The application allows customers to browse products by category, search for items, manage their cart, and send their order directly through WhatsApp.

The project was developed as a practical application of modern frontend development concepts using Vue 3 and TypeScript.

## ✨ Features

- 📋 Responsive digital menu
- 🗂️ Product categorization
- 🔎 Product search and filtering
- 🛒 Shopping cart
- ➕ Add products to the cart
- ➖ Remove products from the cart
- 🔢 Adjust product quantities
- 💰 Automatic total calculation
- 📱 Responsive design for mobile and desktop
- 🧭 Client-side navigation with Vue Router
- 💬 Order checkout through WhatsApp

## 🛠️ Technologies

- **Vue 3** — Frontend framework
- **TypeScript** — Static typing and safer development
- **Pinia** — State management
- **Vue Router** — Client-side routing
- **Tailwind CSS** — Utility-first styling
- **Vite** — Development environment and build tool
- **Lucide** — Interface icons

## 🧩 Project Structure

The project follows a modular structure to keep responsibilities organized and make the application easier to maintain.

```text
src/
├── assets/
│   └── images/        # Project images and visual assets
├── components/        # Reusable UI components
├── composables/       # Reusable Vue logic
├── data/              # Product and application data
├── pages/             # Application pages
├── router/            # Vue Router configuration
├── stores/            # Pinia stores and application state
├── types/             # TypeScript type definitions
├── App.vue            # Root application component
├── main.ts            # Application entry point
└── style.css          # Global styles
```

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Charlesson-MP/ponto-do-lanche.git
```

Navigate to the project directory:

```bash
cd ponto-do-lanche
```

Install the dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at the local address provided by Vite.

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
